[[What is Aesthetic Value]]?：*Philosophical Topics* (2024)に載った拡張版

- 美的価値の問い：(AVQ) なにが美的価値を美的価値とするのか？
- まだ十分な答えがないとしたら、それはAVQがなにを求める問いなのかよく分かっていないから。
    - 前提をカタログ化する。
    - これらの前提に疑問を投げかける。
    - これらの前提に依存しないひとつの答えをアウトライン。
- 以下が諸前提：
	1. AVQは複合的であり、ふたつのシンプルな問いに還元できる。
	    - (AQ) なにが美的価値を美的にするのか？
	    - (VQ) なにが美的価値を価値にするのか？
	2. VQは、美的価値==〔という種[species]〕==の属[genus]を探求している。
	3. VQへの適切な答えは、**合理性制約**を守るべし：美的価値ゆえに対象はどのような種の**理由**を生じさせるのかを特定すべし。==〔「価値を持つ⇔φの理由を与える」という分析が前提なので、φを特定すべし。〕==
	4. AQは、美的価値の個別化条件[differentia]を探求している。
	5. AQへの適切な答えは、**知覚制約**を守るべし：美的価値が知覚的であるとはどういうことか、明確にすべし。
	6. AVQは、属-個別化条件による、美的価値の定義を要求している。
	7. AVQへの答え＝VQへの答え＋AQへの答え
	    - ==〔まず価値という属を特定し、続いて「美的」の個別化条件が特定できれば、合わせて〈美的価値とはなにか〉に答えられる、という方針。〕==
- 以下は前提への疑い：
- 美的価値と価値の関係は、赤い三角と三角への関係ではなく、赤と色の関係ではないか。
    - species/genus関係ではなく、determinate/determinableではないか。
    - **だとすると、AVQはVQとAQには還元できない。**
        - 部分的にすら、AVQはVQに還元できない：AVQへの答えは、VQには認識論的に先行しているので。
        - 部分的にすら、AVQはAQに還元できない：AQとAVQはまさに同じものなので。
    - ==〔アナロジーとして、「①赤色とはなにか」は「②色とはなにか」＋「③なにが色を赤くするのか」には分解できない、ということ。認識論的に言えば、②の手前に①があり、また③は実質①なので。〕==
    - AVQをほかの問いのセットに還元するのも無理。
    - AVQは単純な問い。
    - 上の前提はぜんぶ間違っていることになる。
    - ==〔実質、プレーンバニラ規範性を経由して美的価値を説明する方針全般に反対している。〕==

---

- 以下が、AVQは単純だ==〔複合的ではない〕==と考える理由：
- AVQが複合的だとすれば、美的に価値のあるものは、「価値がある」かつ「美的である」ことになる。
    - 赤い三角形が、赤いかつ三角形であることと同じ？
    - AVQが複合的だとしたら、属valueと個別化条件aestheticは、どちらもaesthetic valueという種[species]に存在論的に先行していなければおかしい。
        - 赤さと三角形性は赤い三角形に先行している。
    - しかし、「価値」という属は、「美的価値」という種より存在論的に後だと思われる。
        - 価値があるから美的に価値あるのではなく、美的に価値あるから価値がある。
        - 例：ダダハリ・モスクは価値があるからこそ美しいのではなく、美しいからこそ価値がある。その個別の美しさは、価値のとりうるひとつのdeterminateである。（raddish-grayが色のdeterminateであるのと同様）
    - 同様に、「美的」という個別化条件も、「美的価値」という種より存在論的に後だと思われる。
        - 価値と結びつかなければaesthetic自体に意味はないので、美的価値には美的価値というそれ自体を除いて個別化条件などない。
        - もちろん、美的価値という種はほかの価値とは異なるが、価値という点において[in respect of value]異なるというだけ。赤という種が他の色たちとは色の点において異なるのと同じ。
        - ==〔価値とは独立にそれを個別化する条件があり、連言となって個別化する、というわけではない。〕==
- AVQが単純であれば、その答えも単純であるはずだ。
- 「AVQへの適切な答えは①合理性制約と②知覚制約を満たさなければならない」というのも、AVQが複合的ではないのならば不要な前提となる。
    - 知覚的かつ合理的だというひとつの制約さえ満たせばよい。
    - この制約は還元不可能：与えるタイプの理由に訴えず知覚的であることが言えないし、知覚的であることに訴えず与えるタイプの理由が言えない。
    - ==〔知覚的本性と、reason-givingされるφは、セットで説明してしまう方針。〕==
- Shelley (2022)：美的価値は、私たちがそれを持ったものとして対象を知覚する、というごくミニマルな意味において知覚的。
    - 「ある対象が美的価値を持っていることを知覚する」＝「美的価値ゆえのある種の理由を生じさせるようなものだと知覚する」
    - 「美的価値ゆえに対象が生じさせるある種の理由」＝「美的価値を対象が持っていると知覚することの理由、まさにその理由を生じさせるものとして対象を知覚することの理由」==〔美的価値ゆえの理由とは、美的知覚（まさにその理由を与えるものとして対象を知覚する）をする理由。美的価値は、美的価値-把握-美的知覚をmeritする、というやつ。〕==
    - 美的価値が美的価値なのは、「ある対象が美的価値を持つ」＝「その対象が、まさにその理由を生じさせるものとして知覚される理由を生じさせるような対象である」から。

> Elsewhere I argue that aesthetic value is perceptual in the minimal sense that we perceive objects as having it (Shelley 2022). Assuming that is right, and taking the above constraint seriously, we get this:
>
> 	To perceive an object as having aesthetic value is to perceive it as being such as to generate whatever kind of reason an object generates in virtue of having aesthetic value.
>
> And so also this:
>
> 	The kind of reason an object generates in virtue of having aesthetic value is a reason to perceive it as having aesthetic value, that is, as being such as to generate that very reason.
>
> And so, finally, this:
>
> 	Aesthetic value is aesthetic value because an object’s having it is its being such as to generate a reason to perceive it as being such as to generate that very reason.

- 以上がAVQへの答え。
    - 美的判断についてのシンプル・セオリー：ある対象に美的価値があると美的判断する＝まさにその知覚を合理化するようなものとして対象を知覚することである。
    - ==〔美しいと判断する＝美しさを知覚する理由を与えるものとして（そのうちに美しさを知覚することが適切であるものとして）対象を知覚する。〕==
    - ==〔一応、形式としては、美的価値の還元的分析ではなく、あくまで美的判断の理論となっている。〕==
    - これは、18世紀の教訓に忠実：美的価値と美的判断は概念的なペアである。
- 「美的知覚をする美的理由がある」が気に入らない人もいるかも。
    - 美的理由からすることはもっといろいろある？==〔たぶんロペスを念頭においている〕==
    - 応答1：①美的理由と、②美的理由を持つおかげで持つ==〔美的とは限らない〕==理由を区別すべし。
        - ==〔ロペスのあれこれは全部、美的理由を持つおかげで持つ実践的な（美的ではないor派生的にのみ美的な）理由たち、ということだろう。まずもって美的価値がある＝美的知覚をmeritするからこそ、収集したり展示するさらなる理由がある。〕==
    - 応答2：この区別をするための理論的リソースを持つべし。==〔自説なら区別できる、ということ。〕==
- 多くの答えられていない問いがあるはず。しかし、正しい質問を提起したはず。
